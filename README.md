One joke about a meeting that should have been an email, written to `entry.txt` by a tiny TypeScript program.

## The joke

The line plays on the loop every office worker knows: a meeting called to discuss an email, followed by an email recapping the meeting, with nothing actually decided in either. The punch lands on the last word — both the meeting and the email said nothing — so it stands alone with no setup and no second sentence.

## Run it

```sh
node main.ts
```
